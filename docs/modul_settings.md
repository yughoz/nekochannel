# Modul Settings (#10, standalone #22)

Preferences disimpan di `userData/settings.json`: reader, notifikasi, bahasa, dock/sidebar dan `sendEnabled` (izin `send_message` Agent/MCP, default OFF, hanya dari Settings > LLM Agent). Key `action` lama (auto-reply, dihapus 2026-11-20) dibuang saat dimuat. Agent, Summary, JEV, webhook, dan MCP diatur di Settings (id/en), bukan lewat edit `.env`. Konfigurasi integrasi disimpan sebagai ciphertext OS Electron safeStorage di `userData/integrations.enc` (0600). Backend `basic_text`/enkripsi tidak tersedia atau file rusak: integrasi gagal tertutup, arsip tetap tersedia, file sumber tidak ditimpa. Tidak ada fallback penyimpanan plaintext.

Agent memakai fallback per-field ke Summary. URL/model kosong mengosongkan override; key kosong mempertahankan key tersimpan. Reset eksplisit menghapus bagian tersebut (MCP merotasi key). Renderer hanya menerima `keySet`, tidak menerima key; copy MCP adalah tindakan clipboard eksplisit. URL hanya HTTP(S), tanpa userinfo/query/fragment; port 1-65535; threshold 0-1. IPC dibatasi ke Settings window dan divalidasi lagi di main process. Renderer Settings tidak mempunyai akses jaringan.

Save integrasi dipersist tetapi tidak memalsukan live apply: status meminta quit dari tray dan restart manual. Tidak ada restart otomatis, kehilangan antrean, atau penghentian service pemilik port lain. Reader toggle langsung berlaku; OFF membatalkan request otomatis yang sedang berjalan dan memblok JEV/summary/forwarding berikutnya, bukan akses arsip/MCP atau chat Agent eksplisit.

Migrasi pertama membaca hanya `.env` milik aplikasi dan environment proses, bukan checkout wa-reader. Nilai app-owned (GUI lama) mengalahkan environment; sesudah `integrations.enc` ada, Settings selalu authoritative. JEV/webhook tetap OFF saat import. `NEKOCHANNEL_ENV` tidak mengimpor integrasi ke GUI; hanya opsi lifecycle backend. Key MCP lama dipertahankan, default MCP tetap ON. Sebelum menghapus baris integrasi/mcp-key lama, sumber asli disimpan dan diverifikasi dalam `integrations-migration.enc` terenkripsi (0600), termasuk snapshot tambahan bila sumber muncul lagi. Migrasi multiline ditolak tanpa menghapus sumber. Tidak membuat backup plaintext baru atau mengubah legacy `.env`.

Backup ciphertext bersama direktori app saat app berhenti; safeStorage terikat OS/keyring, bukan backup portabel. Simpan keyring OS juga. Recovery perlu OS/keyring yang sama dan dekripsi safeStorage di proses main tepercaya; jangan dump key ke console atau renderer. File recovery berisi snapshot sumber asli, bukan konfigurasi aktif; jangan mengganti konfigurasi aktif dengan recovery tanpa memeriksa versinya.

## Paritas legacy

- JEV: POST `<base>/systemone`, Bearer key, model/state/questions `noul`; skor valid 0-1 dibulatkan dua desimal sebelum threshold default 0.6, promo menang dari needs_reply, outgoing tidak diklasifikasi. Timeout 8 detik, concurrency 4, hasil/null tersimpan; OFF tidak membuat cache null permanen.
- Summary: OpenAI-compatible `<base>/chat/completions`, Bearer key/model, fallback deterministik bila tidak tersedia; outgoing tetap konteks, promo dikecualikan. Summary dapat dipakai tanpa JEV.
- Webhook: Authorization adalah key persis (tidak ditambah Bearer), tanpa redirect, timeout 30 detik, semua 2xx sukses. Pending delivery persisten hanya ditandai delivered setelah sukses; retry/event state tetap account-scoped. `pengingat`: DM incoming terakhir belum dibalas >60 menit, kategori/skor memenuhi syarat, quiet 22-06. `ringkasan`: grup jam 12/20 lokal, baseline historis dikecualikan; mention dan freshness safeguards integrasi tetap ada.
- Test webhook meminta konfirmasi dan mengirim payload sintetis `test:true`, tanpa pesan arsip, ke URL tersimpan bahkan jika toggle OFF. Tidak ada test otomatis saat save/startup.
- MCP: toggle, listen port, write-only auth key, status endpoint aktif; port bentrok menonaktifkan MCP saja, arsip/chat tetap berjalan. Bearer auth untuk enam tool read-only: search_messages, get_chat_messages, list_chats, unread_summary, group_members, db_overview, plus `send_message` yang selalu butuh konfirmasi user di app ([modul agent](modul_agent.md)). Snapshot legacy yang tersedia tidak menyertakan MCP/chat, sehingga ini mempertahankan kemampuan backend terintegrasi, bukan klaim perbandingan kode yang tidak ada.

`settings.js` tetap pure Node; UI di settings.html dengan trusted-sender IPC, i18n dari preload dan About versi/repo. Tidak ada kredensial yang dikirim balik ke renderer. Capture tetap read-only; kirim pesan hanya lewat `send_message` saat saklar ON dan disetujui per pesan.

Verifikasi: `npm test`; `node scripts/integrations-smoke.js` memakai dua launch Electron dengan userData sementara, safeStorage OS asli, port ephemeral, key palsu, mock HTTP loopback dan Settings IPC. Clipboard writer diintersep hanya dalam smoke agar clipboard host tidak berubah; ini memverifikasi tindakan copy melalui IPC, bukan clipboard OS. `node scripts/reader-smoke.js` dan `node scripts/privacy-smoke.js` memeriksa regresi reader/privacy. Tes Node enkripsi memakai AES-GCM double, bukan bukti safeStorage OS; smoke Electron memberikan bukti terpisah. Bukan penerimaan production endpoint/WhatsApp nyata.
